# Interactive Histogram Explorer
This Streamlit web application provides a user-friendly interface for exploring the distribution of numerical data in CSV files through interactive histograms.

## Features

* **Easy CSV Upload:** Users can quickly upload their datasets in CSV format using a drag-and-drop interface or a file browser.
* **Data Preview:** The app displays the first few rows of the uploaded data to help users verify the loaded dataset and identify columns.
* **Interactive Column Selection:** A dropdown menu allows users to choose any numerical column from their dataset to visualize.
* **Customizable Histogram:** Users can dynamically adjust the number of bins and the range of the histogram using intuitive sliders in the sidebar. This allows for detailed exploration of the data's distribution.
* **Bin Borders:** The generated histograms include clear black borders around each bin for better visual separation and interpretation.
* **Descriptive Statistics:** The app calculates and displays key descriptive statistics for the selected column, including:
    * Maximum value
    * Minimum value
    * Mode (the most frequent value)
    * Median (the middle value)
    * Average (mean)
    * Standard Deviation (a measure of data spread)
    * Quartiles (25th, 50th, and 75th percentiles)
* **Percentile Calculation:** Users can input a specific percentile (between 0 and 100) in the sidebar, and the app will calculate and display the corresponding value for the selected column.

## Technologies Used

* **Python:** The core programming language.
* **Streamlit:** For building the interactive web application with minimal code.
* **Pandas:** For efficient data manipulation and reading CSV files.
* **NumPy:** For numerical operations.
* **Matplotlib:** For creating the histogram visualizations.

## How to Use

1.  **Upload your CSV file:** Drag and drop your CSV file into the designated area or click "Browse files" to select it from your computer.
2.  **Select a numerical column:** Once the data is loaded, choose the numerical column you want to analyze from the dropdown menu.
3.  **Adjust histogram parameters (optional):** Use the sliders in the left sidebar to change the number of bins and the range of the histogram to explore different perspectives on the data distribution.
4.  **View the histogram:** The interactive histogram will be displayed, reflecting your chosen parameters.
5.  **See descriptive statistics:** Key statistical measures for the selected column will be shown below the histogram.
6.  **Calculate percentiles (optional):** In the sidebar, enter a percentile value (0-100) and click "Calculate Percentile" to see the corresponding data value.
